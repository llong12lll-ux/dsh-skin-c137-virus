# 素材投放目录

把做好的图放进这个目录，文件名用**槽位名**（大小写随意，扩展名随意）。
然后跑：

```sh
python ../tools/apply-artwork.py --dry-run
python ../tools/apply-artwork.py
```

## 不用你准备的东西

favicon（32/192/512）、Windows `.ico`、插件列表图标、皮肤管理预览图、
中英文案、强调色取色 —— 这些由工具或我这边生成。

## 导出要求

- PNG 或 WebP 都行，工具会转。带透明的**别存成 JPG**（透明会变黑）。
- 单张最长边 ≤ 2600px，单张 ≤ 2MB。
- 元素别贴画布边缘画，四周留 2–3% 余量。
- 文件名随便起，但**要能对上槽位名**（比如 `MAID_LEFT.png`、`maid_left_v2.webp` 都行）。
